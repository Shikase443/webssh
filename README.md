# Web SSH

ブラウザからSSH接続するWebターミナルです。ブラウザを閉じてもSSH接続を維持します。

## 起動

```sh
cp .env.example .env
```

`.env`の`APP_TOKEN`を20文字以上のランダムな値に変更して起動します。

```sh
docker compose up -d --build
```

[http://127.0.0.1:8093](http://127.0.0.1:8093)を開き、アクセスキーを入力します。

## 操作

- 左上から新規接続。接続先の「＋」で別セッションを追加。
- タブの×は表示を閉じ、電源アイコンはSSHを切断。切断後の矢印で再接続。
- 選択した文字列を自動コピーし、中ボタンで貼り付け。HTTPSまたはlocalhostとクリップボード利用許可が必要。

保存するパスワードは平文です。SSHホスト鍵は変更時も自動登録します。コンテナを再起動するとSSH接続と履歴は失われます。
